## MainType Highlights

- **Font Library:** MainType font library is the shelf of typefaces you already have, listed so a name is not buried in a folder.
- **Font Tag:** MainType font tag marks a face for a purpose, such as “poster,” “notes,” or “headings.”
- **Glyph View:** MainType glyph view opens the letters themselves so you can see weight, italics, and odd characters.
- **Font Info:** MainType font info shows family details and other facts stored in the font file.
- **Type Sample:** MainType type sample sets your own words in the face so readability is judged on a real line.

---

## What Is MainType

MainType is a library helper for people who collect type for study and small projects. MainType font library is the index. MainType font tag is how you mark what a face is good for. A student building a presentation, or someone at home making a program for a recital, can filter the shelf instead of scrolling every file.

MainType glyph view is the close look: one letter, then another, until you know the personality of the face. MainType font info answers practical questions about the family. MainType type sample puts a sentence you wrote into that family. The point is a calm choice, not a production studio. You tag, you look, you sample, and you return to the same library next week.

Keep tags boring and useful. “Body,” “title,” and “handout” are enough. MainType font library stays browsable, MainType glyph view settles arguments about a strange character, and MainType type sample stops you from picking a face that looks clever and reads poorly.

## Starting with MainType

Prerequisites: A compatible computer, typefaces you may use, and permission to run MainType.

1. **Prepare:** Decide three tags you will actually reuse, such as body, title, and notes.
2. **Open The Library:** Browse MainType font library and find faces you already know.
3. **Tag A Few:** Apply MainType font tag to those faces only.
4. **Inspect Letters:** Open MainType glyph view on a title candidate.
5. **Read The Facts:** Check MainType font info so you know the family name you mean.
6. **Set A Line:** Type your real heading into MainType type sample and keep or reject the face.
